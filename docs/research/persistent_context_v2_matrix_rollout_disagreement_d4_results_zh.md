# D4 完整预测轨迹分歧开发实验结果

日期：2026-08-25  
证据等级：前瞻 development feasibility，不是 formal，不验证在线 gate  
状态：采集、原始数据审计和统计审计均有效

## 1. 问题与方法

跨形状实验中，固定 `α=0.75` 的物理上下文平均有效，但仍有一部分序列受损。D4 检验能否在 E2 执行前，利用默认模型和上下文模型的预测轨迹分歧给受损场景排序。

每条序列先规划 population 和 context 两套命令，再保存四条完整 latent 预测轨迹。真实环境此时尚未执行。主风险分数提前固定为：

```text
RMS[上下文模型预测(context命令) - 默认模型预测(context命令)]
```

预注册方向为“分数越大，使用 context 越危险”。真实收益为：

```text
benefit = pose_auc10(population) - pose_auc10(context 0.75)
```

`benefit<0` 表示使用 context 后受损。

## 2. 数据与有效性

- 数据来自作者 seed-42 的 `I、L、十字、小T、方块、Z` 六个形状池。
- 排除既有跨形状 smoke、formal 和 reserve 的 228 个片段。
- 新选 6 条 smoke 和 96 条 development sequence，共 204 个互异片段。
- Development 中每个形状组合 16 条，每个旋转—增益因素 12 条，每个“形状组合×因素”有 2 条。
- 选择过程不读取新 E2 outcome。
- Smoke 与 development 的独立重放中，latent、状态、目标损失和指标最大误差均为 `0`；模型和随机状态未改变。

## 3. 主要结果

| 项目 | 结果 |
|---|---:|
| 序列数 | 96 |
| population 平均误差 | 2.6194 |
| context `α=0.75` 平均误差 | 2.3078 |
| context 平均收益 | +0.3116，改善 11.90% |
| 平均收益 95% bootstrap 区间 | [0.2191, 0.4110] |
| 改善 / 持平 / 受损 | 71 / 1 / 24 |
| 受损率 | 25.00% |
| 主风险分数识别受损的 AUC | 0.3906 |
| AUC 95% bootstrap 区间 | [0.2664, 0.5223] |
| 主分数与 `-benefit` 的 Pearson / Spearman | -0.4711 / -0.4663 |

预注册方向没有成立。主分数越大时，context 平均收益反而越高：

| 主分数四分位 | 平均收益 | 受损率 |
|---|---:|---:|
| 最低 25% | +0.1011 | 33.33% |
| 25%–50% | +0.1308 | 20.83% |
| 50%–75% | +0.3143 | 33.33% |
| 最高 25% | +0.7002 | 12.50% |

因此，这个分歧量更接近“context 对预测影响有多大”的强度信号。它不能按预注册方向作为风险 veto。不能在同一批数据上把方向翻转后再声称得到了已验证的 gate。

| context 命令的末步模型分歧 | 0.4028 | -0.4504 |
| 默认模型下两套命令的全轨迹分歧 | 0.3854 | -0.4783 |
| 默认模型下两套命令的末步分歧 | 0.4005 | -0.4607 |
| 上下文模型下两套命令的全轨迹分歧 | 0.4583 | -0.4402 |
| 上下文模型下两套命令的末步分歧 | 0.4728 | -0.4034 |
| 默认模型对 context 命令的相对目标损失 | 0.3953 | -0.4132 |
| 上下文模型对 population 命令的相对目标损失 | 0.4693 | -0.3987 |

| context 命令对模型变化的目标损失敏感度 | 0.6134 | +0.4143 |

最后一个目标损失差方向上有一定风险信号，但它是预定义次要分析，没有独立区间或新数据验证，不能替换主分数。

固定的 leave-one-shape-pair-out ridge 对连续收益的相关性为 `0.4428`，但零阈值策略在 96 条中选择 context 95 次。它的平均收益仍为 `0.3115`，受损率仍为 `25%`，没有形成有用的场景级选择策略。

## 5. 异质性

六个形状组合的平均收益均为正，范围为 `+0.2065` 至 `+0.4597`。`十字→小T` 的受损率最高，为 `43.75%`；其均值区间跨 0。其余组合受损率为 `12.5%–31.25%`。

八个因素中，`rotation=+10°, gain=1.18` 的平均收益为 `-0.0414`、受损率 `50%`；`rotation=-10°, gain=1.18` 的平均收益接近 0。其余六个因素平均收益为正。该异质性说明 factor 本身仍然重要，但 D4 的主要目标是同 factor 内的场景风险排序，不能用事后 factor 表代替主检验。

Population 先执行和 context 先执行各 48 条，平均收益分别为 `+0.3679` 和 `+0.2552`。每个分支都从相同初态和环境种子重置，独立重放完全一致；该组间差异按描述性抽样波动记录，不解释为执行污染。

## 6. 结论与后续边界

1. 新数据再次确认正确的跨形状旋转—增益上下文有平均价值：改善 `11.90%`，区间为正。
2. 受损尾部仍存在：24/96 条受损。
3. D4 预注册的完整轨迹 RMS 分歧不能识别这些受损场景，当前 rollout-risk veto 路线未得到支持。
4. 次要 ridge 几乎退化为 always-context，没有带来风险控制价值。
5. 不应在这 96 条上翻转主方向、调阈值或挑选次要特征后直接启动 formal。

如果继续投入，新的科学问题应从“执行前分歧 veto”转为“E2 开始后如何用少量真实反馈修正旧上下文”。可检验 E1 后验作为 E2 初始先验，再用前 1–2 步运动在线更新；对照应同时包含 factor 持续和 factor 改变。该路线需要新的合同与等动作预算设计，不能由 D4 自动授权。
