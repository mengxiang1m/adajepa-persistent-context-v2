# Persistent Context V2 固定效果门撤销与历史结果重读

日期：2026-08-22

## 当前规则

按用户最新指示，撤销所有用固定效果百分比、固定同向比例或置信区间跨零状态自动裁决 `GO/NO-GO` 的规则。后续实验只做两类判断：

1. **有效性审计**：实现、身份配对、预算、RNG、factor 生命周期和 raw artifact 是否正确；错误时可判 `INVALID`。
2. **连续证据报告**：报告均值方向、绝对/相对效应、置信区间、正向配对比例、ties、factor/任务异质性和负对照，不自动输出研究停止命令。

历史预注册文件和 raw 输出不能在结果生成后静默改写；其中的旧阈值和旧机器裁决只用于说明当时怎样得出结论，现已失去对后续研究的约束力。

## 之前真实 benchmark 的重读

补充：PointMaze lag A 的辅助 `AUC10` 为 `+0.19%`、`65.6%` 配对正向，但区间跨 0，且不是预先指定的主指标；应如实报告为“辅助窗口略正但不确定”，不能替换主指标。

旧 P0A 只有 `3/12` blocks 正向且总体主效应为负，不属于“多数正向却被门槛挡掉”。合成 Persistent Context V2 Stage 0–3 的效应很强，原本就通过旧门，不受此次改判影响。旧 `persistent-actuator-factor-oracle-v1` 有弱 cost 收益，但其关键问题还包括 success 饱和以及收益可被 population prior/no-persistence 或平滑解释，不能仅归因于固定效果量门。

## 对 PushObj 的直接影响

当前证据已经支持：true factor 在 PushObj rotation 上平均改善行为，且两个候选都呈多数配对正向。下一步可以由用户授权 history/RLS 实验，用来回答非特权历史估计能否回收这部分 oracle 收益；不得再以旧 25%/70% 门为由阻止实验。
