# Persistent Context V2 方案汇报

## 一、核心想法

E1 和 E2 是 episode，不是两种任务类别。一个 episode 是一次从初态运动到目标的完整控制回合；一条实验序列由前后两个 episode 组成：

| 记号 | 含义 | 作用 |
|---|---|---|
| E1 | 第 1 个 episode，称为证据回合 | 执行任务并记录控制指令与实际运动，用来估计物理参数 |
| E2 | 第 2 个 episode，称为评价回合 | 从新初态完成新目标，用来检验 E1 的物理上下文是否有用 |
| 一条序列 | `E1 → E2` | 实验的统计单位 |

E1 和 E2 使用不同场景。本文再按物体形状划分任务类别：形状相同、起点和目标不同，称为同类不同场景；物体形状不同，称为跨类或跨形状。

我们分别研究两种序列：

| 序列类型 | E1 与 E2 的关系 | 要回答的问题 |
|---|---|---|
| 同形状序列 | 都使用 T 形物体，起点和目标不同 | 物理上下文能否帮助同类新任务冷启动 |
| 跨形状序列 | 使用不同物体形状，起点和目标也不同 | 从一种形状识别的物理上下文能否迁移到另一种形状 |

每种序列又包含两种物理条件。持续条件下，E1 与 E2 使用相同的执行器旋转和动作增益；非持续对照中，E2 的旋转和增益发生改变。这个对照用于判断收益是否真的来自持续物理信息。

执行器旋转和动作增益属于设备级因素，可以在物体形状变化时保持不变。物体重心属于对象级因素，只有同一物体跨回合使用或实验合同明确规定重心持续时才能复用。当前跨形状正式结果只针对执行器旋转和增益，不包含重心迁移。

E1 结束后，估计出的低维物理上下文被传给 E2。环境状态、规划器缓存和 AdaJEPA 模型更新不跨 episode 保留。

```mermaid
flowchart LR
    A["E1：证据 episode<br/>记录动作与运动"] --> B["估计并保存<br/>旋转—增益上下文"]
    B --> C["E2：评价 episode<br/>新起点和目标"]
    C --> D["与不用历史的规划<br/>进行配对比较"]
```

当前证据最完整的是“旋转—增益”上下文。它描述控制指令经过执行器后，方向偏了多少、幅度放大或缩小了多少。两种序列使用同一套估计器和规划修正方法，差别只在 E1 与 E2 的物体形状是否相同。

## 二、实现思路

### 1. E1：证据 episode

E1 先用默认模型规划并执行 10 步动作。每一步记录规划器发出的控制指令，以及圆形推块器执行前后的位置和速度。估计器只能看到这些运动记录，不能读取环境中设置的真实旋转角和增益，也不保存目标位置或物体轨迹作为任务模板。

同形状实验的 E1 使用 T 形物体；跨形状实验的 E1 使用 I、L、十字、小 T、方块或 Z 形物体。两者收集的是同一种“控制指令如何实际生效”的证据。

### 2. 估计旋转和增益

控制指令与实际生效动作满足：

```text
实际动作 = 增益 × 旋转矩阵 × 控制指令
```

执行器的控制规律已知，因此可以根据执行前后的位置和速度反推出实际生效动作，再用多步观测更新二维贝叶斯后验：

```text
控制指令 + 执行前后运动状态
→ 反推实际动作
→ 估计旋转角和增益
→ 保存后验均值、协方差和有效观测数
```

E1 结束后清空环境状态、规划器缓存和随机状态，只把后验均值、协方差和有效观测数带入 E2。E2 不读取 E1 的起点、目标和物体轨迹，因此跨形状实验传递的内容不是任务解法。

### 3. 控制上下文强度

完整使用估计结果可能伤害部分场景，因此在默认矩阵与估计矩阵之间做插值：

```text
E2 使用矩阵 = (1-α) × 默认矩阵 + α × 估计矩阵
```

`α=0` 表示不使用历史信息，`α=1` 表示完整使用。当前默认设置为 `α=0.75`。这个设置同时用于同形状和跨形状实验。当 E1 与 E2 的物理参数改变时，E1 后验不再代表 E2，继续使用它属于非持续对照。

我们也训练过一个低容量策略，根据估计出的旋转和增益在 `0、0.25、0.5、0.75、1` 中选择强度，但它没有稳定超过固定 `0.75`。

### 4. E2：评价 episode

E2 使用新的起点和目标。同形状序列继续使用 T 形物体；跨形状序列换成另一种形状。CEM 规划器先生成候选控制序列，再用上下文矩阵计算这些指令预计会如何生效。冻结世界模型据此预测物体轨迹，规划器选出预测结果最接近 E2 目标的 10 步动作，并在真实环境中执行。

```text
E1 记录控制指令与推块器运动
→ 估计旋转—增益矩阵
→ 清空 E1 的任务状态
→ 以 α=0.75 修正 E2 规划
→ CEM 选择动作
→ 分别统计同形状或跨形状结果
```

## 三、实验设置和结果

### 1. 主要设置

| 项目 | 设置 |
|---|---|
| 环境 | PushObj / PushT |
| 统计结构 | 一条序列包含 E1 证据 episode 和 E2 评价 episode |
| 同形状序列 | `T→T`；两个回合使用不同场景 |
| 跨形状序列 | `I→L、L→十字、十字→小T、小T→方块、方块→Z、Z→I` |
| 持续条件 | E1、E2 的旋转和增益相同 |
| 非持续对照 | E1 与 E2 的旋转—增益不同；其余变量按合同配对和平衡 |
| 每回合动作数 | 10 |
| 旋转角 | `-25°、-10°、10°、25°` |
| 动作增益 | `0.82、1.18` |
| CEM | 200 个候选、30 个优选、10 轮更新 |
| 世界模型 | 全程冻结 |
| 主要指标 | 10 步平均位姿误差，越低越好 |
| 统计单位 | 序列；置信区间按序列重采样 20,000 次 |

每条序列都配对运行不用历史、正确历史、错误序列历史、非持续历史和真实参数上限。针对同一个 E2，各策略共享物体形状、初态、目标、真实物理参数、随机种子和动作预算；唯一变化是规划器收到的历史上下文。这样可以把上下文本身的作用与场景难度分开。

### 2. 同形状序列：T→T

E1 和 E2 都使用 T 形物体，但对应不同起点、目标和轨迹片段。E1 是证据 episode；E2 是评价 episode，并在读取任何当前 episode 的运动之前使用 E1 后验。

| 实验 | 结果 | 说明 |
|---|---:|---|
| 旋转—增益持续，正确使用 E1 历史 | 误差改善 `9.53%`，24/32 条序列改善 | 同类新场景具有冷启动收益 |
| 旋转—增益改变，继续使用旧历史 | 误差退化 `20.02%` | 旧物理信息会造成负迁移 |
| 固定 `α=0.75`，独立 T 形正式集 | 改善 `12.48%`，受损率 `21.88%` | 当前同形状默认方案 |
| 自适应强度策略，独立 T 形正式集 | 改善 `13.21%`，受损率 `21.88%` | 相对固定 `0.75` 的额外优势不确定 |

因此，同形状结果支持在场景改变、物理参数持续时复用 E1 上下文。它没有测试形状改变，这部分由下一组实验单独回答。

### 3. 跨物体形状迁移

E1 与 E2 使用不同形状，同时更换起点和目标。正式实验包含 `I→L、L→十字、十字→小T、小T→方块、方块→Z、Z→I` 六个有向组合，共 96 条序列。每条序列只把 E1 估计出的旋转—增益后验传给 E2。

| 物理条件与方法 | 结果 | 说明 |
|---|---:|---|
| 旋转—增益持续，固定 `α=0.75` | 改善 `9.97%`，受损率 `28.13%` | 六个形状组合的平均效果均为正 |
| 旋转—增益持续，完整使用上下文 | 改善 `10.69%`，受损率 `36.46%` | 平均值更高，负向尾部也更大 |
| 旋转—增益改变，继续使用 E1 历史 | 改善 `-0.22%`，受损率 `59.38%` | 跨形状收益依赖物理参数持续 |

这组结果说明，E1 保存的内容至少包含可跨形状复用的执行器标定信息。结论范围限于作者发布的 PushObj 数据、同一状态和动作接口、同一冻结世界模型及当前六个形状组合。它不能直接外推到 PushObj 与 PointMaze 之间，也不能证明物体重心能够跨形状迁移。

## 四、当前结论和下一步

目前有两层正式证据。第一层是同形状迁移：T 形物体的起点和目标改变时，持续的旋转—增益上下文能够改善 E2 冷启动。第二层是跨形状迁移：E1 与 E2 使用不同物体形状时，同一上下文仍然平均改善闭环结果。两层证据都要求物理参数在 E1→E2 边界持续；参数改变时，收益消失或出现明显负迁移。

固定 `α=0.75` 是当前最稳妥的设置，但跨形状正式实验仍有 `28.13%` 的序列受损。下一步将同时记录默认模型和上下文模型预测的两套轨迹，检查两者的预测分歧能否在 E2 执行前识别高风险场景。该实验会分别报告同形状和跨形状表现，并保留物理参数改变的对照；确认风险信号有效后再设计新的上下文选择策略。
