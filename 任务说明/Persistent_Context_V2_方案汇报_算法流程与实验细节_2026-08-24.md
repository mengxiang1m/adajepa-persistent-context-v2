# Persistent Context V2 方案汇报

## 一、核心想法

E1 和 E2 是两个 episode。一个 episode 是一次完整的控制回合。一条实验序列由 E1 和 E2 组成。

| 记号 | 含义 | 作用 |
|---|---|---|
| E1 | 第 1 个 episode，称为证据回合 | 执行任务并记录控制指令与实际运动，用来估计物理参数 |
| E2 | 第 2 个 episode，称为评价回合 | 从新初态完成新目标，用来检验 E1 的物理上下文是否有用 |
| 一条序列 | `E1 → E2` | 实验的统计单位 |

E1 和 E2 使用不同场景。我们按物体形状区分两种序列：

| 序列类型 | E1 与 E2 的关系 | 要回答的问题 |
|---|---|---|
| 同形状序列 | 都使用 T 形物体，起点和目标不同 | 物理上下文能否帮助同类新任务冷启动 |
| 跨形状序列 | 使用不同物体形状，起点和目标也不同 | 从一种形状识别的物理上下文能否迁移到另一种形状 |

持续条件下，E1 和 E2 的旋转、增益相同。对照实验会改变这些参数，用来检查旧信息是否仍然有效。

E1 结束后，只把估计出的旋转和增益传给 E2。环境状态、规划器缓存和模型更新都不保留。

```mermaid
flowchart LR
    A["E1：证据回合<br/>记录动作与运动"] --> B["估计并保存<br/>旋转—增益上下文"]
    B --> C["E2：评价回合<br/>新起点和目标"]
    C --> D["与不用历史的规划<br/>进行配对比较"]
```

当前实验研究“旋转—增益”上下文。旋转表示动作方向偏差，增益表示动作幅度变化。

## 二、实现思路

### 1. E1：证据回合

E1 用默认模型规划并执行 10 步动作。每一步保存控制指令，以及推块器执行前后的位置和速度。

### 2. 估计旋转和增益

控制指令与实际生效动作满足：

```text
实际动作 = 增益 × 旋转矩阵 × 控制指令
```

根据执行前后的位置和速度，可以反推出实际动作。多步观测共同更新二维贝叶斯后验：

```text
控制指令 + 执行前后运动状态
→ 反推实际动作（u实际 = [ (p后-A·p前-B·v前) / C - p前 ] / 100）
→ 估计旋转角和增益
  （cᵢ=u指令·u实际/||u指令||²，sᵢ=u指令×u实际/||u指令||²；
    ĝ=√(μ_c²+μ_s²)，θ̂=atan2(μ_s,μ_c)）
→ 保存后验均值、协方差和有效观测数
  （Λ=Λ₀+N·I/σ²，η=η₀+∑ᵢzᵢ/σ²；
    Σ=Λ⁻¹，μ=Ση，n=N）
```

其中，`p前`、`p后` 是执行前后的位置，`v前` 是执行前的速度。当前控制配置下，`A=0.70433、B=0.02993、C=0.29567`。这些数由 PD 控制规律确定，不参与学习。

`×` 表示二维有向叉积，`zᵢ=(cᵢ,sᵢ)`。`μ=(μ_c,μ_s)` 是后验均值，`Σ` 是后验协方差，`N` 是有效观测数，观测噪声 `σ=0.01`。`Λ₀、η₀` 来自训练因素形成的先验。

估计出的旋转角和增益会合成一个二维变换：

```text
E1 旋转—增益矩阵 = 估计增益 × R(估计旋转角)
```

`R` 表示二维旋转矩阵。保存内容包括 E1 旋转—增益矩阵、参数协方差和有效观测数。

### 3. 控制上下文强度

完整使用 E1 的估计结果可能伤害部分场景。因此，E2 在两个旋转—增益矩阵之间插值：

```text
E2 旋转—增益矩阵
= (1-α) × 默认旋转—增益矩阵
  + α × E1 旋转—增益矩阵
```

默认旋转—增益矩阵来自训练因素的平均值。`α=0` 表示不用 E1 历史，`α=1` 表示完整使用 E1 估计。当前默认值是 `0.75`。自适应强度策略没有稳定超过这个固定值。

### 4. E2：评价回合

E2 使用新的起点和目标。CEM 先生成候选动作，再用 E2 旋转—增益矩阵计算动作的实际效果。冻结的世界模型预测物体轨迹。规划器选择最接近目标的 10 步动作并执行。

## 三、实验设置和结果

### 1. 主要设置

| 项目 | 设置 |
|---|---|
| 环境 | PushObj / PushT |
| 每回合动作数 | 10 |
| 旋转角 | `-25°、-10°、10°、25°` |
| 动作增益 | `0.82、1.18` |
| CEM | 200 个候选、30 个优选、10 轮更新 |
| 世界模型 | 全程冻结 |
| 主要指标 | 10 步平均位姿误差，越低越好 |
| 统计单位 | 序列；置信区间按序列重采样 20,000 次 |

实验比较不用历史、正确历史、错误历史、参数改变和真实参数五种情况。同一个 E2 共享初态、目标、随机种子和动作预算。

### 2. 同形状序列：T→T

E1 和 E2 都使用 T 形物体。E2 在产生本回合运动记录前读取 E1 后验。

| 实验 | 结果 | 说明 |
|---|---:|---|
| 旋转—增益持续，正确使用 E1 历史 | 误差改善 `9.53%`，24/32 条序列改善 | 同类新场景具有冷启动收益 |
| 旋转—增益改变，继续使用旧历史 | 误差退化 `20.02%` | 旧物理信息会造成负迁移 |
| 固定 `α=0.75`，独立 T 形正式集 | 改善 `12.48%`，受损率 `21.88%` | 当前同形状默认方案 |
| 自适应强度策略，独立 T 形正式集 | 改善 `13.21%`，受损率 `21.88%` | 相对固定 `0.75` 的额外优势不确定 |

### 3. 跨物体形状迁移

跨形状实验共 96 条序列。形状组合为 `I→L、L→十字、十字→小T、小T→方块、方块→Z、Z→I`。E1 和 E2 的起点、目标也不同。两者之间只传递旋转—增益后验。

| 物理条件与方法 | 结果 | 说明 |
|---|---:|---|
| 旋转—增益持续，固定 `α=0.75` | 改善 `9.97%`，受损率 `28.13%` | 六个形状组合的平均效果均为正 |
| 旋转—增益持续，完整使用上下文 | 改善 `10.69%`，受损率 `36.46%` | 平均值更高，负向尾部也更大 |
| 旋转—增益改变，继续使用 E1 历史 | 改善 `-0.22%`，受损率 `59.38%` | 跨形状收益依赖物理参数持续 |

旋转—增益信息可以跨形状复用。这个结论只适用于当前 PushObj 数据和冻结模型。我们还没有测试 PushObj 到 PointMaze 的迁移。

## 四、当前结论和下一步

旋转和增益保持不变时，E1 上下文对同形状和跨形状的 E2 都有帮助。参数改变后，旧上下文会失效，甚至造成负迁移。

固定 `α=0.75` 是当前默认设置，但跨形状实验仍有 `28.13%` 的序列受损。下一步记录默认模型和上下文模型的预测轨迹，检查预测分歧能否提前发现高风险场景。
