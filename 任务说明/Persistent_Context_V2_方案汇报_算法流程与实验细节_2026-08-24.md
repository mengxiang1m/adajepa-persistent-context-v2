# Persistent Context V2 方案汇报

## 一、核心想法

同一组任务中，物体形状、起点和目标会变化，但某些物理参数会持续不变，例如执行器的方向偏差、动作增益或物体重心。

我们把任务分成两个回合：第一回合 E1 用来识别物理参数，第二回合 E2 使用识别结果完成新任务。跨回合只保存低维物理上下文，AdaJEPA 的模型权重保持冻结。

```mermaid
flowchart LR
    A["E1 执行任务<br/>记录动作与实际运动"] --> B["估计低维<br/>物理上下文"]
    B --> C["E2 使用上下文<br/>修正规划预测"]
    C --> D["与默认模型<br/>配对比较"]
```

当前证据最完整的是“旋转—增益”上下文。它描述控制指令经过执行器后，方向偏了多少、幅度放大或缩小了多少。

## 二、实现思路

### 1. 第一回合：收集物理证据

E1 先用默认模型规划并执行 10 步动作。每一步记录规划器发出的控制指令，以及圆形推块器执行前后的位置和速度。估计器只能看到这些运动记录，不能读取环境中设置的真实旋转角和增益。

### 2. 估计旋转和增益

控制指令与实际生效动作满足：

```text
实际动作 = 增益 × 旋转矩阵 × 控制指令
```

执行器的控制规律已知，因此可以根据执行前后的位置和速度反推出实际生效动作，再用多步观测更新二维贝叶斯后验：

```text
控制指令 + 执行前后运动状态
→ 反推实际动作
→ 估计旋转角和增益
→ 保存后验均值、协方差和有效观测数
```

E1 结束后清空环境状态和规划器缓存，只把上述后验带入 E2。

### 3. 控制上下文强度

完整使用估计结果可能伤害少数场景，因此在默认矩阵与估计矩阵之间做插值：

```text
E2 使用矩阵 = (1-α) × 默认矩阵 + α × 估计矩阵
```

`α=0` 表示不使用历史信息，`α=1` 表示完整使用。当前默认设置为 `α=0.75`。我们也训练过一个低容量策略，根据估计出的旋转和增益在 `0、0.25、0.5、0.75、1` 中选择强度，但它没有稳定超过固定 `0.75`。

### 4. 第二回合：修正规划

E2 的 CEM 规划器先生成候选控制序列，再用上下文矩阵计算这些指令预计会如何生效。冻结世界模型据此预测物体轨迹，规划器选出预测结果最接近目标的 10 步动作，并在真实环境中执行。

```text
E1 记录动作与运动
→ 估计旋转—增益矩阵
→ 以 α=0.75 写入 E2 规划
→ CEM 选择动作
→ 真实环境执行并计算误差
```

## 三、实验设置和结果

### 1. 主要设置

| 项目 | 设置 |
|---|---|
| 环境 | PushObj / PushT |
| 每条序列 | E1、E2 各一个回合 |
| 每回合动作数 | 10 |
| 旋转角 | `-25°、-10°、10°、25°` |
| 动作增益 | `0.82、1.18` |
| CEM | 200 个候选、30 个优选、10 轮更新 |
| 世界模型 | 全程冻结 |
| 主要指标 | 10 步平均位姿误差，越低越好 |
| 统计单位 | 序列；置信区间按序列重采样 20,000 次 |

每个场景都配对运行默认模型、正确历史、错误历史、物理参数改变和真实参数上限。各策略共享初态、目标、物理参数、随机种子和动作预算。

### 2. 旋转—增益上下文

| 实验 | 结果 | 说明 |
|---|---:|---|
| T 形物体，正确历史 | 误差改善 `9.53%`，24/32 条序列改善 | 低维上下文具有闭环价值 |
| E2 物理参数改变后继续用 E1 历史 | 误差退化 `20.02%` | 收益依赖物理参数持续 |
| 固定 `α=0.75`，独立正式集 | 改善 `12.48%`，受损率 `21.88%` | 当前默认方案 |
| 自适应强度策略 | 改善 `13.21%`，受损率 `21.88%` | 相对固定 `0.75` 的额外优势不确定 |

### 3. 跨物体形状迁移

E1 与 E2 使用不同形状，共测试 96 条序列，形状包括 I、L、十字、小 T、方块和 Z。

| 方法 | 结果 |
|---|---:|
| 正确历史，固定 `α=0.75` | 改善 `9.97%` |
| 完整使用上下文 | 改善 `10.69%`，但受损率更高 |
| E2 物理参数改变 | 改善 `-0.22%`，受损率 `59.38%` |

这说明 E1 识别出的旋转和增益可以迁移到不同形状的 E2 任务；物理参数改变后，这种迁移价值随之消失。

### 4. 其他路线

| 路线 | 结果 | 当前决定 |
|---|---|---|
| 保存在线更新后的部分模型权重 | 没有稳定超过每回合重置，部分任务出现干扰 | 停止扩展 |
| 动作延迟上下文 | 延迟识别 32/32 正确，持续与非持续条件都只改善约 `0.3%` | 暂停 |
| 物体重心上下文 | 真实重心上限改善 `26.87%`；现有预测器仅改善 `4.68%/0.37%` | 预测器能力不足 |
| 重心的 100 Hz 接触实验 | 冲量信息有局部增量，完整模型未超过 10 Hz 模型或零响应 | 不训练第三版预测器，不启动重心历史估计器 |

## 四、当前结论和下一步

目前已经证明：低维旋转—增益上下文可以从 E1 迁移到 E2，在同形状和跨形状任务中改善闭环结果。固定 `α=0.75` 是当前最稳妥的使用方式。

主要问题是约四分之一的场景仍会受损。下一步将同时记录默认模型和上下文模型预测的两套轨迹，检查两者的预测分歧能否提前识别高风险场景。该实验只做风险信号验证，确认有效后再设计新的上下文选择策略。
